# VPP 자동매매 전략 · 백테스트 프레임워크

퀀트 트레이딩의 구조를 전력 도매시장 입찰에 그대로 옮긴 모듈입니다.

```
전략 라이브러리 → 백테스트 엔진 → 성과지표 비교(리더보드) → 운영 배포
```

## 실행

```bash
cd backend
python scripts/benchmark_strategies.py --days 150                 # 리더보드
python scripts/benchmark_strategies.py --days 150 --walk-forward  # 시간순 3분할 검증
python scripts/benchmark_strategies.py --forecast-error 0.2       # 예측이 더 나쁠 때
```

결과는 `models/strategy_benchmark.json`에 저장되고, 아래 API가 그대로 서빙합니다.

| Method | Path | 설명 |
|---|---|---|
| GET | `/market/strategies` | 전략 목록 + 백테스트 성과 + 활성 전략 |
| GET | `/market/strategies/leaderboard` | 리더보드 원본 |
| POST | `/market/strategies/activate` | 운영 전략 교체 (in-memory) |
| GET | `/market/strategy-bids?strategy=zscore` | 해당 전략의 24구간 추천 입찰 |

## 주식 퀀트와의 대응

| 주식 | VPP 입찰 |
|---|---|
| 종목 유니버스 | 24개 시간 구간 |
| 포지션 사이즈 | 입찰 수량(kW) |
| 지정가 주문 | 입찰가 — MCP 이하일 때만 체결(낙찰) |
| 슬리피지·수수료 | 배터리 열화비용 + 미이행 위약금 |
| 레버리지 한도 | 방전 정격(kW) · 가용 에너지(kWh) |

**결정적 차이는 에너지 예산 제약입니다.** 주식은 같은 종목을 계속 살 수 있지만
배터리는 하루 총 방전량이 정해져 있습니다. 낙찰돼도 낼 에너지가 없으면 위약금을 뭅니다.
전략의 성패는 사실상 *"한정된 에너지를 어느 시간대에 쓸 것인가"* 하나로 수렴합니다.

## 전략 목록

| 이름 | 계열 | 핵심 아이디어 |
|---|---|---|
| `flat90` | rule | 90원 고정 응찰. 가격 신호 무시 — 최악의 기준선 |
| `topk_peak` | rule | 예측 상위 K구간 집중. 에너지 제약 미고려 |
| `topk_safe` | rule | 위와 동일하되 **에너지 예산 강제** — 제약 하나의 효과를 보는 대조군 |
| `greedy_budget` | optimize | 마진 상위 구간부터 예산 소진 |
| `marginal_value` | optimize | 에너지 기회비용을 응찰가에 반영 (희소할수록 비싸게) |
| `zscore` | statistical | 일중 z-score 기준 진입. 변동성 낮은 날은 관망 |
| `vol_scaled` | statistical | 가격 스프레드에 비례해 노출 조절 (변동성 타겟팅) |
| `cvar_guard` | statistical | 예측 오차 꼬리 리스크 반영, 예산의 일부만 노출 |
| `cem_policy` | learned | 기존 CEM 학습 신경망 (`models/bid_policy.json`) |
| `ensemble` | meta | 구성 전략들의 수량·가격 중앙값 |
| `bandit` | meta | 일별 실현손익으로 가중치 갱신, 국면 변화 시 자동 전환 |

## 성과지표

퀀트 표준 지표를 그대로 씁니다.

- **수익성**: 일평균 손익, 연환산, 누적
- **위험조정**: Sharpe, Sortino, Calmar
- **위험**: 변동성, 최대낙폭(MDD), VaR 5%, CVaR 5%, 최악의 날
- **거래 품질**: 승률, Profit Factor, 낙찰률, **이행률**, 위약금 비중

전력시장 특유의 지표는 **이행률**과 **위약금 비중**입니다. 수익이 높아도
이행률이 낮으면 계통 운영자 신뢰를 잃어 장기적으로 퇴출됩니다.

## 편향 방지

- **룩어헤드 차단** — 전략은 예측 곡선만 봅니다. 실현 MCP는 정산에서만 등장합니다
- **예측 오차 주입** — AR(1) 자기상관 + 수준 편향. `--forecast-error`로 조절 (기본 10%)
- **이행 불확실성** — 급전 시점 가용 에너지가 계획과 다릅니다 (기본 σ=25%)
- **워크포워드** — 시간순 분할. 무작위 분할은 미래 정보가 새는 통로라 쓰지 않습니다
- **부트스트랩 신뢰구간** — 우연히 이긴 것인지 가릅니다

## 결과 해석 시 주의 (정직한 한계)

1. **Sharpe가 20을 넘습니다.** 주식이라면 말이 안 되는 수치입니다. 이 사업이
   차익거래에 가깝고(가격이 오르는 시간대에 방전) 용량요금이 하방을 받쳐주기
   때문입니다. **실제로는 여기 모델링되지 않은 위험**(시장 규칙 변경, 정산 지연,
   설비 고장, 경쟁 심화로 인한 가격 잠식)이 있으므로 이 값을 그대로 홍보하면 안 됩니다.

2. **상위 3개 전략의 신뢰구간이 겹칩니다.** `zscore`·`topk_safe`·`vol_scaled`는
   통계적으로 구분되지 않습니다. "z-score가 최고"라고 말하는 건 과대주장입니다.

3. **학습 정책(`cem_policy`)이 단순 규칙보다 못합니다.** 제약을 지키는 단순 규칙
   (`topk_safe`)이 학습 모델보다 5배가량 높습니다. 기존 홍보 문구("AI가 룰 전략을
   이긴다")는 *제약을 모르는* 룰과 비교한 결과라는 점을 알고 있어야 합니다.
   → 재학습 시 에너지 제약을 보상함수에 명시적으로 넣는 것이 개선 방향입니다.

4. **시장 영향(market impact)이 없습니다.** 우리 물량이 커지면 MCP가 눌립니다.
   현재 규모에서는 무시할 만하지만, 사업계획의 확장 시나리오에서는 반영해야 합니다.
